## 4. Bảo Mật Video & Chống Tải Xuống Trái Phép (Zero-Cost Architecture)

1. **Player Phía Client (`<x-secure-video-player>`):**
   - Vô hiệu hóa Context Menu chuột phải (`@contextmenu.prevent="return false;"`).
   - Ngăn chặn phím tắt DevTools/Inspection (`F12`, `Ctrl+Shift+I`, `Ctrl+Shift+J`, `Ctrl+U`, `Ctrl+S`).
   - Thẻ `iframe` được bảo vệ với `referrerpolicy="strict-origin-when-cross-origin"` và sandbox policies.
   - Thủy ấn / Protection badge tinh tế góc dưới: "S-cool Protected Stream".

2. **Backend Video Streaming Controller (`SecureVideoStreamController`):**
   - Ký URL tạm thời (`URL::temporarySignedRoute` với `hasValidSignature()`).
   - Kiểm tra nghiêm ngặt `Referer` và `Origin` header nhằm chặn công cụ download bên ngoài hoặc hotlinking.
   - Lọc và chặn User-Agent của các phần mềm tải tự động (IDM, curl, wget, python, v.v.).
   - Trả về header an ninh: `X-Content-Type-Options: nosniff`, `Content-Disposition: inline`, `Cache-Control: must-revalidate, no-cache, no-store, private`.

## 6. Tính Năng Tải Lên Ảnh Bìa Khi Tạo Community (Custom Cover Upload)

- **Giao diện Tạo Cộng Đồng (`communities.create`):**
  - Đã kích hoạt `enctype="multipart/form-data"` trên form tạo mới.
  - Thêm khu vực tải lên ảnh bìa tương tác với Alpine.js: Hỗ trợ click hoặc kéo thả file ảnh từ thiết bị cá nhân (JPEG, PNG, WebP tối đa 2MB, tối đa 4096×4096px).
  - Tự động hiển thị khung xem trước (Preview) tỷ lệ 16:9 ngay sau khi người dùng chọn ảnh, kèm nút "Change" hoặc "Remove" linh hoạt.
- **Xử lý Backend An toàn (`CommunityController@store`):**
  - Kiểm tra tính hợp lệ của file ảnh (kích thước, định dạng, độ phân giải).
  - Lưu trữ vào disk bảo mật `community_media` theo thư mục chuẩn `{community_id}/{hash}.{ext}`.
  - Tự động dọn dẹp file rác nếu database transaction gặp sự cố.
